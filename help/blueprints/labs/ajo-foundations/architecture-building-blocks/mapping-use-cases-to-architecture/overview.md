# Asignación de casos de uso a la arquitectura

## Objetivos de aprendizaje

Al final de este laboratorio, usted será capaz de:

- Aplique un marco de toma de decisiones estructurado para evaluar casos prácticos de marketing en el mundo real
- Identifique los componentes de arquitectura de AJO necesarios para admitir cada caso de uso
- Seleccione el motor de orquestación adecuado (Campañas orquestadas o Recorridos) y justifique la recomendación
- Explicar las decisiones de arquitectura correctas para los tres casos de uso de Connection 5G y articular las señales que impulsaron cada uno
