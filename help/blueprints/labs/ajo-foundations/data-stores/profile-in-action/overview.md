# Perfil en acción

## Requisitos previos

>[!WARNING]
>
>Los siguientes laboratorios deben haber sido completados antes de comenzar este laboratorio

- [Instalación de Postman](../../postman-setup/postman-installation.md)

Si no ha completado estos laboratorios, hágalo ahora antes de continuar.

## Resumen de laboratorio

En este vídeo aprenderá cómo este laboratorio simula una visita a una página web desde Edge Network a Adobe Experience Platform y cómo validará el perfil resultante, la calificación de segmentos y el evento del lago de datos.

>[!VIDEO](https://video.tv.adobe.com/v/3491061/)

## Objetivos de aprendizaje

En este ejercicio, simularemos una visita de página web desde una fuente de Edge a Adobe Experience Platform. ¿Con qué te vas después de tomar este laboratorio?

- Creación y configuración de una secuencia de datos en Adobe Experience Platform
- Envío de un evento web de prueba a Edge Network mediante Postman
- Validar la creación de perfiles y la calificación de segmentos en el perfil en tiempo real
- Confirme que el perfil existe en Edge, pero aún no en el conjunto de datos de instantánea de perfil
- Compruebe que el evento se haya almacenado en el lago de datos
