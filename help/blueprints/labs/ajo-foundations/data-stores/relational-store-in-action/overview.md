# Almacenamiento relacional en acción

## Resumen de laboratorio

En este vídeo aprenderá cómo se integra la tienda relacional con el perfil del cliente en tiempo real y lo que hará en este laboratorio para examinar esquemas relacionales, configurar una Dimension de segmentación de perfiles y crear y probar una campaña orquestada.

>[!VIDEO](https://video.tv.adobe.com/v/3486539/)

## Objetivos de aprendizaje

- Examinar esquemas y ver relaciones
- Configuración de un Dimension de destinatario de perfil
- Creación de una campaña organizada mediante diversas actividades de flujo de trabajo
- Construya una audiencia con una actividad Leer audiencia y utilice atributos del esquema relacional
- Pruebe la campaña y comprenda el comportamiento al usar audiencias de AEP junto con el esquema relacional
