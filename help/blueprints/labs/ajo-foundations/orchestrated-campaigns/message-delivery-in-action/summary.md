# Resumen

A través de este laboratorio realizó las siguientes actividades:

- Creación de una campaña organizada
- Se ha creado una audiencia para los miembros del plan básico mediante la actividad Generar audiencia
- Ramificó la audiencia para crear dos ramas y utilizó los canales de correo electrónico `Profile-Email` y `Relational-Email` respectivamente para enviar mensajes
- Se ha probado la campaña para conocer la diferencia de comportamiento entre los dos canales de correo electrónico configurados
