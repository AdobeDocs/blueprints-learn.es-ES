# Transmitir un evento de pedido

## Prerrequisitos

1. Ha descargado los [archivos de ejemplo](../sample-files.md) y ve el archivo denominado —> **Lab\_Single\_Order\_sample.json**
1. Ha completado correctamente el laboratorio [Using Data Landing Zone](./using-data-landing-zone/overview.md) y tiene una asignación válida establecida para importar

## Desafío

Realice el siguiente conjunto de tareas tal como lo hizo en el laboratorio anterior.

1. Cree una nueva cuenta con el conector de origen de la API HTTP
1. Configure un flujo de datos con la nueva cuenta para transmitir datos a su propio conjunto de datos de pedidos del cliente
1. Volver a utilizar el conjunto de asignaciones del laboratorio [Using Data Landing Zone](./using-data-landing-zone/overview.md)
1. En Postman, rellene **Crear evento de pedido** con la información necesaria para transmitir correctamente los datos y adjuntarlos al registro de cuenta de cliente creado anteriormente
1. Verifique que el pedido esté vinculado a su perfil
