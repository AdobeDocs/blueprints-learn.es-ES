Este laboratorio introducirá transformaciones de datos complejas y el procesamiento de datos JSON.

¿Cuáles son las principales conclusiones de este laboratorio?

- Explicación de la ingesta por lotes de datos JSON anidados
- Utilice la copia de objetos como concepto para simplificar las asignaciones de campos entre campos complejos que no son XDM y XDM.
