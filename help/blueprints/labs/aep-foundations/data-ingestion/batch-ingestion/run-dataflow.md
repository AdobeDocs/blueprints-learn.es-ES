# Ejecutar flujo de datos

Si todo parece correcto, continúe y haga clic en el botón **Finalizar** en la esquina superior derecha para ejecutar la carga de datos.

Después de hacer clic en **Finalizar**, volverá a la pantalla **Flujos de datos**. La creación del flujo de datos debería tardar unos minutos. La primera carrera debería comenzar en un par de minutos.

![Pantalla de flujos de datos que muestra el flujo de datos y el estado de ejecución recién creados](assets/run-dataflow-dataflows-sources-screen.png)

>[!NOTE]
>
>Debe actualizar la página continuamente para ver la actualización de estado, ya que el backend no inserta actualizaciones en la interfaz de usuario.

>[!NOTE]
>
>Si ha activado todas las alertas, recibirá una alerta en el explorador, en la esquina superior derecha del explorador, cuando el flujo comience a ejecutarse y se complete o falle correctamente
