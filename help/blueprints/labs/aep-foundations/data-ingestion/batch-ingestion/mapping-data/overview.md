# Datos de asignación

## Información general

En la pantalla Asignación, el motor de recomendación de AI/ML asignará varios atributos automáticamente entre los campos del conjunto de datos de origen y los campos de esquema. Estas asignaciones automatizadas se denominan asignaciones de paso a través, pero requieren **inspección cuidadosa**, ya que a menudo se producen errores y asignaciones incorrectas.



![Pantalla de asignación que muestra recomendaciones contextuales basadas en AI/ML para asignaciones de paso a través](assets/overview-ai-ml-based-contextual-recommendations.png "recomendaciones contextuales basadas en AI/ML")

>[!NOTE]
>
>Las recomendaciones de AI/ML están basadas en el contexto y la pantalla puede tener un aspecto diferente a la captura de pantalla anterior o diferir del vecino

>[!NOTE]
>
>Tenga en cuenta que todas las columnas de origen se tratan SIEMPRE como cadenas
