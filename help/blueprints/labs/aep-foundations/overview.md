# Información general

## Lo que aprenderá

1. **Traducción relacional a NoSQL:**
   - Comprender la arquitectura, el modelado y el ensamblado del perfil del cliente en tiempo real
   - Aplicar la metodología LID a un escenario ficticio para modelar el cliente en tiempo real
1. **Modelo de datos de experiencia (XDM):**
   - Conozca los componentes de XDM y su relevancia para el comportamiento del Perfil del cliente en tiempo real
   - Práctica práctica con la creación de esquemas mediante la interfaz de usuario y la API
1. **Ingesta de datos y creación de perfiles:**
   - Diferenciación entre varios almacenes de datos en Adobe Experience Platform
   - Obtenga información sobre el procesamiento de datos para fuentes de flujo y por lotes
   - Laboratorios prácticos para introducir datos y crear perfiles
1. **Segmentación/Activación y Generación de audiencias:**
   - Explicación de los formularios de evaluación de segmentos admitidos por el Perfil del cliente en tiempo real
   - Funcionalidades de perfil de Hub diferenciado frente a Edge
   - Cree y active audiencias en la interfaz de usuario, incluido el trabajo con destinos de flujo continuo



## Audiencia de destino

- Arquitectos de soluciones
- Arquitectos empresariales
- Desarrolladores
- Ingenieros de datos
- Arquitectos de datos



## Experiencia recomendada o familiaridad

- Conceptos de base de datos (crear, actualizar, eliminar)
- Conceptos de modelado de datos (filas, campos, claves, etc.)
- Uso de API de REST
- Comprensión general de Adobe Experience Platform
- Exposición a CDP, tecnología de publicidad, CRM u otras pilas de tecnología de marketing
