# Conferencias

XDM (Experience Data Model) es el marco de trabajo estandarizado de Adobe para organizar los datos de experiencia del cliente en diferentes sistemas. Garantiza que los datos de varias fuentes, como sitios web, aplicaciones y CRM, se estructuren de forma coherente, lo que facilita la unificación, el análisis y la activación en tiempo real. Esta coherencia es crucial para crear perfiles de cliente precisos, permitir experiencias personalizadas y admitir perspectivas impulsadas por IA en Adobe Experience Platform.
