# Modelado de API

## Resumen de laboratorio

Trabajar con las API de Experience Platform es fundamental para comprender cómo automatizar y poner en funcionamiento varias funciones de la plataforma. Definir esquemas y comprender cómo se describen los datos mediante esos esquemas es una de las primeras cosas que un cliente hará en Adobe Experience Platform al definir su arquitectura de datos.

Este laboratorio le presentará la experiencia de diseño de esquemas de Adobe Experience Platform utilizando solo las API. Aprenderá a crear sus propios esquemas utilizando componentes XDM existentes, añadiendo sus propias personalizaciones en XDM e identificando y creando varios descriptores de identidad para su uso con el perfil del cliente en tiempo real.

## Objetivos de aprendizaje

Poder crear un esquema utilizando solo las API de Experience Platform a través de una variedad de componentes básicos de XDM, como:

1. Clases
1. Grupos de campos
1. Descriptores
   1. Identidades (incluidas las principales)
   2. Relación
   3. Referencia
