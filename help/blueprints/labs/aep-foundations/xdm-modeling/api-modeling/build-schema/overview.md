# Crear esquema

## Ensamblado de esquema

Todos los esquemas que forman parte de XDM se componen del mismo modo.  Un esquema siempre está compuesto por una sola clase y uno o más grupos de campos. Además, la clase de un esquema dicta cómo interpretarán los datos otros sistemas de Experience Platform (es decir, como una serie basada en registros o en series temporales).

![Diagrama que muestra un esquema compuesto por una clase y uno o más grupos de campos](assets/overview-schema-assembly.jpeg "Ensamblado de esquema")


## Su objetivo

En este laboratorio creará el esquema de cuenta del cliente de Connection 5G utilizando la hoja de asignación que rellenó anteriormente. Cuando haya terminado con esta parte del laboratorio, debería ver un esquema similar al siguiente:
